# Cafe POS MVP

## Быстрая демонстрация

После `npm start` откройте `http://localhost:3000/demo`. Это автономный экран для показа: вход
`admin` / `admin`, столы, меню и заказы сохраняются только в браузере. PostgreSQL для него не нужен.
Кнопка «Сбросить демо» возвращает исходные данные. Пароль `admin` предназначен только для демонстрации,
не для реальной кассы.

Для показа на телефоне подключите телефон к той же Wi-Fi сети и откройте
`http://<IP-адрес-компьютера>:3000/demo`. Демо-официант: `waiter` / `waiter`.
Данные демо сохраняются отдельно в каждом браузере, поэтому это не многопользовательская рабочая касса.

Это кассовое MVP: сотрудники и роли, столы, меню, заказы, отмена с причиной, оплата и равное разделение счёта.

## Первый запуск

1. Создайте PostgreSQL базу `cafe` и примените схему: `psql -U postgres -d cafe -f sql/schema.sql`.
2. Используйте `.env.example` как шаблон и задайте `DATABASE_URL` и длинный случайный `JWT_SECRET` в переменных окружения терминала или сервиса запуска.
3. Запустите `npm start` и откройте `http://localhost:3000/cashier`.
4. Создайте первого администратора запросом `POST /auth/register`. Пока таблица `users` пуста, этот единственный запрос доступен без токена. Все последующие учётные записи может создавать только администратор.

Пример тела первого запроса:

```json
{"name":"Администратор","login":"admin","password":"change-this-password","role":"admin"}
```

Для реальной кассы перед использованием добавьте резервное копирование базы, аудит действий и интеграцию с фискальным оборудованием согласно требованиям вашей страны.
